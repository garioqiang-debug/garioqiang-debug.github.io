# 摄影站 · 现代版（底片档案）

> 单文件自包含的自然摄影站，与 `G:\个人网站-重构版`（第一版）、`G:\个人网站-合并版`（旧站）并行存在，互不覆盖。
> 视觉语言与 `G:\个人网站-重构版-现代\作品集` 完全同源：深墨绿 + 酸性苔绿 + 大圆角 + 颗粒，外加一支暗房琥珀（amber）专门承担"编号 / 奖项 / 待归"。

## 一、文件结构

```
个人网站-重构版-现代/
└── 摄影/
    ├── index.html          # 唯一页面：样式、脚本、文案全部内联（约 65 KB）
    └── assets/
        └── img/            # 13 张：6 张真实照片 + 5 张图版 + 1 张天蛾生态照 + 二维码
```

- **没有本地 `.css` / `.js`**。改配色、改文案、改编号，全都在这一个 `index.html` 里。
- 图片一律相对路径 `assets/img/xxx.jpg`，整个文件夹搬走也不会断图。
- 字体走 `miaoda.feishu.cn` 自托管镜像（Noto Serif SC + Inter），断网自动退回系统宋体/黑体。
- 全部图片都是**静态 `<figure><img src>`**，文件名直接写在 `src` 里，发布链路能扫到，不会出现"图藏进 JS 数组里、上线后裂图"的问题。

## 二、本地预览

双击 `摄影/index.html` 即可，不需要服务器。

- 浅色版：`index.html?theme=light`；深色版：`index.html?theme=dark`。点右上角太阳按钮可切换，选择会记在浏览器里（键名 `scicom-photo-theme`）。
- 档案区的 chips 是筛选（全部 11 / 获奖 2 / 野外 4 / 图版 5），翻页器每页 6 版（620–980px 4 版、≤620px 2 版）——**分页只影响铺陈，不影响灯箱**：点任意一张进灯箱，仍是筛选后 26 格的连续索引，键盘 `←/→/Esc` 可翻页与关闭，手机可左右滑。
- 灯箱里连续翻会翻到"待归底片"，那一格显示的是 `NEGATIVE MISSING` 空状态，不是坏图。
- 切筛选条件会回到第 1 页；屏宽跨过 620 / 980 两个断点时也会回到第 1 页（每页数变了）。

## 三、部署

Cloudflare Pages（免费），与作品集同一套流程：

1. 新建项目 → 上传 `摄影` 文件夹**里面的内容**（`index.html` 必须在根目录，不能多套一层）。
2. 直接用 `xxx.pages.dev` 或绑定自定义域名；原定域名 `scicom-photo.pages.dev`。
3. 无构建、无后端、无环境变量。

体积：单 html 65 KB（上限 20 MiB），整包 2.81 MB（上限 50 MiB）。后续加图请把单张压到长边 1600px、300 KB 以内。

## 四、怎么改

| 想改什么 | 改哪里 |
|---|---|
| 配色 / 明暗 | `:root` 的 `--bg / --panel / --accent / --amber`；浅色在 `[data-theme="light"]` 块 |
| 首屏主图 | `.hero-frame` 里的 `p-spidersix.jpg`（1:1 裁切，换图保持方形构图） |
| 首屏四个数字 | `.hero-stats` 里四条 `.stat`；改数量时同步改页脚"11 版入档 / 15 张待归" |
| 一张图版 | 对应 `<figure class="card">` 的 `data-cat`（award / field / plate，决定筛选）、`data-title`、`data-note`（灯箱底部说明）、`img src` |
| 筛选计数 | `.chips` 里每个 `<b>` 与 `#sheetCount` 的初始文字（脚本在点击时会自动重算，静态初值要手改） |
| 每页几版 | 脚本里的 `sheetPer()`（现为 `>980px ? 6 : 620px 以上 4 : 2`，与旧站一致）；分页用独立 `.card.pg-off` 类，别改成 `hidden`，否则灯箱索引会断 |
| 待归底片 | `.neg` 块，`N-xx` 编号 + 标题 + 文件名，都在里面 |
| 奖项文案 | 获奖区两条 `.award-card` + `jury` 框 |
| 二维码 | 换 `assets/img/wx-qrcode.png`，同名覆盖 |
| 三站互链 | 页脚的 `.foot-links` |

**补回丢失的原图**：把真图按**同名**放进 `assets/img/`（例：`w-lappet.jpg`），然后把对应 `.neg` 块换成一张 `<figure class="card">`（照现有卡片结构复制一份、改编号标题即可），计数 15 → 14 顺带改页脚。

## 五、这一版做了什么

- **不假装是美图站**：旧站 20 张图里 14 张是恢复期的占位图（960×640、图上印着 RESTORED PLACEHOLDER）。这一版把能核实的 6 张真照片用上（2019 全国昆虫摄影比赛获奖原片，从 `G:\过往经历-个人文档\2020\20190611 昆虫摄影比赛\` 取原图重新压缩），剩下的**不放假图**，改成"待归底片"抽屉：只写编号、标题、文件名，点开是空状态 + 说明。
- **底片档案**：11 版混排（2 获奖 + 4 野外 + 5 图版），CSS 多列瀑布流双列，按真实比例排，不统一裁成同一种画幅——摄影站的画幅本身是信息。
- **灯箱**：11 版 + 15 张待归 = 26 格连续索引，图片模式与 `NEGATIVE MISSING` 空状态共用一个舞台。
- **交互**：吸顶毛玻璃导航 + 阅读进度条 + 颗粒 + 顶部柔光；筛选 chips 吸顶；卡片 45ms 错峰入场；灯箱键盘/滑动；主题切换走 View Transitions 圆形扩散；`prefers-reduced-motion` 下全部降级。
- **移动端**：导航压成第二行（横滑不换行，不再直接隐藏）；档案单列通栏；待归底片 2 列；联系块纵排、二维码 132px。

## 六、已知限制

- 6 张真照片只有 2019 年那一批，2019 之后的野外/夜拍作品原图仍未找回，所以档案区现在是 11 版而非原计划的 12+版。
- 概念图（双联、标本四视图、分类学图版）用的是旧站留下的合成图版，不是原始拍摄文件；`plate-taxonomy.jpg` 只有 622 px 宽，只适合当"证据插图"放在背景区，不适合进瀑布流大图位。
- 没有 `srcset` 多档变体；档案变多之后再加。
- 站内没有文章正文，只到"约稿/授权"这一层。
