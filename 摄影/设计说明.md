# 摄影站设计说明 · 底片档案 / 暗房

## 一、为什么不做"美图站"

旧摄影站是常规画廊：一排缩略图、点开看大图、几段自我介绍。问题是这一版**没有 20 张能用的图**——恢复出来的 14 张是占位图，真图只有 2019 年那 6 张。硬做画廊就得放占位图，等于给访客看空抽屉还装作是作品。

所以换了一个诚实且更专业的容器：**底片档案**。摄影师的硬盘里本来就长这样——有编号、有文件名、有"这张底片不在了"的记录。把缺失也当成档案的一部分展示，比塞假图体面，而且正好把"我是做分类学的"这件事讲清楚。

## 二、视觉语言（与作品集同源）

| 元素 | 摄影站的处理 |
|---|---|
| 底色 | 深墨绿 `#0a0e0b`，浅色 `#f2f0e7`（与作品集完全一致） |
| 强调色 | 酸性苔绿 `--accent`：标题里的半句、主按钮、状态灯、筛选选中 |
| 第二支色 | 暗房琥珀 `--amber`：编号（PLATE 01）、奖项药丸、待归底片虚线格 |
| 字体 | 标题 Noto Serif SC（宋，带博物志的书卷气）；正文 Inter/思源黑；数字与编号等宽 |
| 形状 | 大圆角（16–22px）、细线边框、极轻面板浮起；不做玻璃拟态、不做彩色渐变 |
| 质感 | SVG feTurbulence 颗粒覆盖全页 + 顶部柔光，让深色不显"显示器黑" |

**关键取舍**：不给照片加任何滤镜、不做圆角以外的裁切变形。这个站的"设计感"全部来自排版、留白和字体，照片本身保持原样。

## 三、页面结构

1. **首屏**：左边三行标题 + 一段自述 + 三个标签 + 两个按钮；右边 1:1 主图（六脚蜘蛛，二等奖那幅），图上有 FIG.01 与奖项药丸，底部一条渐变压暗保证字压得住图。下面一条四格数据：02 项 / 06 幅 / 11 版 / 15 张。
2. **获奖**：左侧短笛牧童大图（三等奖那幅），右侧两条奖项记录 + 一个虚线 `jury` 框写评审口径与落选的四幅。用数据说事（25 省区 2762 幅投稿、一等奖 4 / 二等奖 8 / 三等奖 39 / 优秀奖 22）。
3. **底片档案**：吸顶 chips 筛选 + 双列瀑布流 11 版。每张卡是"图上角标 + PLATE 编号 + 标题 + 物种/构图 + 年份与身份"四层信息，点击进灯箱。
4. **待归底片**：15 个虚线琥珀负片格，只写 `N-01 / 标题 / 文件名`。点开是空状态，写明怎么补（同名放回 `assets/img/`）。
5. **图鉴供图**：天蛾悬停吸蜜的生态照 + 《中国天蛾科图鉴》的供稿说明，说明"野生活体照与手绘图版互补"。
6. **背景**：左侧一句主张（照片不是装饰，是生境、寄主、行为的证据），右侧三段自述 + 三个事实 + 一张跨两列的**论文图版**（学名、模式标本编号、现行名并列）。这张图版只有 622px 宽，放进瀑布流会被压成一条白带，所以单独提到这一区当"证据插图"。
7. **授权**：A 图片授权 / B 约拍与摄影指导 / C 科普配图定制，三张卡。
8. **联系**：绿面板 + 真二维码，写清"要图请说明用途、尺寸、期限；约拍给时间地点目标物种"。
9. **页脚**：三站互链 + 底片档案统计。

## 四、两个专门的判断

**为什么图版和照片混排？**
生态照（野生活体）、微距（双联/四视图）、科研图版（标本与标注）对摄影师是三种不同的产出，不是三种"好看程度"。混排且各自标注身份，等于在页面上直接回答"你会拍到什么、会交付什么"。

**为什么"待归底片"不做成灰块占位？**
灰块会让人以为是加载失败或故意留白；写编号+标题+文件名，读者立刻明白这是"有记录、图不在了"。这是档案语言，不是设计缺陷。真图回来后按同名文件放回即可归位，页面上也把这句话写给了访客看。
