# 课程站 · 现代版（教案目录）

> 单文件自包含的静态页。与 `G:\个人网站-重构版`（第一版）、`G:\个人网站-合并版`（旧站）并行存在，互不覆盖。
> 视觉语言与「作品集 · 现代版」「摄影 · 现代版」同一套：深墨绿 / 酸性苔绿 + 圆角 + 颗粒 + 衬线标题；**本站在同色板上默认「纸面浅色」**，用来把"课程 = 印刷教参"的气质和另两站区分开。

## 二、本地预览

双击 `index.html` 即可，无需服务器。

- 主题：默认纸面，点右上角圆钮切深色；也可用 URL 参数强制：`index.html?theme=paper` / `?theme=dark`。
- 选择会被记住，键名 `scicom-courses-theme`。
- 建议直接看这几处交互：① 点时间轴任一阶段 → 目录自动筛出那几年的课；② 点课程行 → 行内展开教案抽屉；③ 点 chips → 目录按标签过滤（计数写在 chip 上）。

## 五、怎么改

1. **改课程内容**：改 `../course-data.json`（或改旧站的 `data_courses.js` 后重跑 `dump-data.js`），再 `node build.js`。每门课字段：`id / title / dt / era / form / age / duration / scale / brief / points[] / tools[] / outcome`。
2. **改文案**：模板里的静态句子在 `index.tpl.html`；由数据渲染的句子在 `course-data.json`。
3. **改配色**：两端都在 `index.tpl.html` 的 `:root` 与 `[data-theme="dark"]`；强调块上的文字色用 `--on-accent`，改强调色时一并改它。
4. **改时长刻度**：`app.js` 的 `BINS`（6 档）与 `binOf()` 的判定顺序，两者要一起动。
5. **改每页门数**：`app.js` 的 `coursePer()`（现为 `innerWidth > 980 ? 8 : 4`，与旧站一致）；改完 `renderPager()` 会自动重算页数。
6. **把封面牌换成真照片**：在 `course-data.json` 里给某门课加 `cover` 字段（图片路径），`app.js` 生成封面牌时若有 `cover` 就输出静态 `<img src="assets/img/xxx.jpg">`。**注意**：图片必须写成静态 `src`，不能藏在 JS 字符串里，否则发布会扫不到链路。
7. **加一门课**：往 `COURSES` 里加一条即可，编号按数组顺序自动生成（C-01…），筛选/计数/统计会同步变。

## 六、已知限制

- 目录里"时长"是归一化刻度（≤45′ / 90′ / 2–3h / 半天 / 一天 / 多日），原始写法仍以小字显示在刻度下。
- 课程标签会重叠（8 个 chip 的计数加起来 28 > 22），这是真实口径，不是算错。
- 全站无课程现场照：旧站可用的真实现场照几乎没有（唯一像现场照的一张含未成年人正脸与品牌 logo，已弃用），详见 `设计说明.md`。展开抽屉里的"封面"是同色板 CSS 设计牌，不是照片；数据里加 `cover` 字段可换成真图。
- 数据口径停在 2026.09；新增课程请同时更新阶段区间与统计。
