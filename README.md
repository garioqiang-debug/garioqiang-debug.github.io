> 单文件自包含的三个静态站，与 `G:\个人网站-重构版`（第一版）、`G:\个人网站-合并版`（旧站）、`G:\个人网站1125`（合并版早期快照）并行存在，互不覆盖。
> 统一视觉语言：深墨绿底 + 单一酸性苔绿强调 + 大圆角 + 颗粒质感 + 衬线标题。摄影站额外用一支暗房琥珀承担"编号 / 奖项 / 待归"，课程站额外用一支批注红承担"编号 / 获奖 / 口径"，且默认纸面浅色。

三个站各自独立，可以单独发布、单独替换，互不依赖。

- 页面不依赖任何本地 `.css` / `.js`，**改颜色、改文案都在各自那一个 `index.html` 里**。
- 图片全部相对路径 `assets/img/xxx.jpg`，跟着文件夹走，换机器不会断图。
- 字体走 `miaoda.feishu.cn` 自托管镜像（Noto Serif SC + Inter），断网退回系统宋体/黑体，版式不塌。

## 二、本地预览

双击各自的 `index.html` 即可，无需服务器。

深浅主题用 URL 参数控制：`index.html?theme=light`（课程站是 `?theme=paper`）/ `?theme=dark`，也可点右上角按钮切换，选择会被记住（键名分别 `scicom-writing-theme` / `scicom-photo-theme` / `scicom-courses-theme`）。

## 三、部署

Cloudflare Pages（免费），三个站各建一个项目：

1. 新建项目 → 上传对应文件夹**里面的内容**（`index.html` 必须在根目录，不能多套一层）。
2. 用 `xxx.pages.dev` 或绑定自定义域名：作品集 `scicom-writing.pages.dev`，摄影 `scicom-photo.pages.dev`，课程 `scicom-courses.pages.dev`。
3. 无构建命令、无后端、无环境变量。

注意：单文件上限 20 MiB（作品集 76 KB、摄影 65 KB、课程 87 KB），整包上限 50 MiB（作品集 2.52 MB、摄影 2.81 MB、课程 0.24 MB）。加图请把单张压到长边 1600px、300 KB 以内。

## 四、作品集 · 现代版

数据、卡片、弹层全部内联在一个文件里，改文案在 `<script>` 顶部的几个数组里：`ARTICLES`（作品）、`FEATURED`（精选六篇）、`THEMES`（主题分组）、`BOOKS`（图书）、`HONORS` / `SERVICES`（资质与服务）。详细字段与"新增一篇文章的标准动作"见 `作品集/README.md`。

- **视觉**：深墨绿 + 酸性苔绿 + 圆角 + SVG 颗粒 + 顶部柔光；标题衬线、正文无衬线、数字等宽。
- **首屏（原版编辑部式）**：左栏 `PUBLISHED WORKS · 2017—2026` 抬头 + 两句大标题 + 一句自述 + 三个入口 + 一行数据脚注；右栏 `CREDENTIALS · 资质` 2×2（标签 / 名称 / 说明），中缝一条竖线；底纹是 46px 方格纸自上而下渐隐。首屏不再放二维码——联系统一走底部。
- **我在写什么，以及为谁写**：紧随首屏的第一屏，两栏原文（两条写作主线 + 我的科普观）。
- **精选六篇**：3 × 2 网格（≤1000px 两列、≤620px 单列），不再横滑；整张卡片即原文外链。
- **交互**：吸顶毛玻璃导航 + 阅读进度条；吸顶筛选 chips + 翻页器（8 / 4 篇每页）；卡片常显三个标签、整张卡片直跳首发原文；图书悬停 3D 微倾斜、点开是详情弹层；主题切换走圆形扩散；`prefers-reduced-motion` 全降级。
- **移动端**：680px 以下首屏单栏、资质单列、精选与作品单列、联系块纵排、二维码 78→160px 自适应。

## 五、摄影 · 现代版（底片档案）
